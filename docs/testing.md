# Проверка проекта

## Зафиксированный результат

Проверка проведена 18 октября 2026 года в Chromium/Edge через Playwright. Программные результаты сохранены в `docs/verification.json` и `docs/accessibility.json`. Генерируемые снимки страниц остаются в игнорируемой папке `test-results/`.

- Статическая проверка: 8 страниц, локальные ссылки и якоря, отсутствие повторных id, связи label/ARIA, наличие обязательных компонентов, порядок CSS и версия Bootstrap.
- Браузерная проверка: 8 групп сценариев; все 8 страниц на ширинах **320, 375, 768, 1024, 1440 px**; отсутствие горизонтального выхода контента.
- Проверены изображения, отсутствие ошибок JavaScript и HTTP 404. Внешние ресурсы сайта блокировались: работа сохранялась.
- axe-core 4.10.3: на начальных состояниях всех 8 страниц нет автоматически найденных нарушений WCAG 2 A/AA и WCAG 2.1 AA. Это автоматическая проверка, а не сертификат полной доступности. Пункты `incomplete` требуют ручной оценки, например текста поверх иллюстраций.
- Ручная визуальная проверка desktop и mobile: сетка, иллюстрации, карточки, форма, отступы и подтверждение заявки.

На данном компьютере антивирус Kaspersky добавляет свой внешний скрипт в HTTP-ответы. Браузерный тест отдельно блокирует этот домен и учитывает его как вмешательство окружения. В файлах репозитория этого скрипта нет. Остальные внешние запросы считаются ошибкой теста.

## Статическая проверка

Из корня проекта:

```sh
python tests/static_check.py
```

Ожидается сообщение `PASS: 8 pages ...`. Для запуска достаточно Python 3 и стандартной библиотеки.

## Браузерные тесты

Для разработчика требуются Node.js, npm и тестовые зависимости:

```sh
npm install
npx playwright install chromium
```

В первом терминале запустите сервер:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Во втором терминале:

```sh
npm run test:browser
npm run test:accessibility
```

На Windows тест использует установленный Edge, если он доступен; иначе Playwright Chromium. Для теста доступности можно явно задать `BROWSER_PATH`. Для браузерного теста можно изменить `TEST_BASE_URL`; исходный адрес — `http://127.0.0.1:4173`.

Папка `test-results/` содержит JSON-отчёты и полные скриншоты каждой страницы на 375 и 1440 px. Она исключена из Git, как и `node_modules/`. Эти инструменты не входят в зависимости работающего сайта.

## Повторная сборка

```sh
python tools/build.py
python tests/static_check.py
```

Если изменены генератор, данные, стили или поведение, повторите соответствующие браузерные проверки. Изменения только документации не требуют повторного запуска всех UI-сценариев.
