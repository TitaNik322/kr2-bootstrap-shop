# KeyboardShop

Магазин клавиатур на Bootstrap 5.3.8: семь моделей, фильтры, избранное и форма заявки с проверкой данных.

**Контрольная работа №2.** Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## О проекте

Сайт продолжает тему магазина клавиатур из первой работы. Это отдельная реализация на Bootstrap: раскладка построена на `container`, `row`, `col-*` и классах отступов, интерактивные компоненты работают через Bootstrap JS Bundle. Для магазина выбраны единая зелёная палитра, реальные фотографии и сдержанная типографика.

Используются HTML, CSS, JavaScript и Bootstrap. Сборщик, npm и серверная часть для просмотра не нужны.

## Подключение Bootstrap

Bootstrap **5.3.8 подключён локально**, без CDN. В проекте сохранены compiled-файлы и лицензия MIT:

```html
<!-- В head: собственные стили после фреймворка -->
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css" />
<link rel="stylesheet" href="css/custom.css" />

<!-- Перед закрытием body: библиотека, данные, затем логика страницы -->
<script src="vendor/bootstrap/js/bootstrap.bundle.min.js"></script>
<script src="js/products.js"></script>
<script src="js/main.js"></script>
```

Bundle содержит Popper и код компонентов. Копии библиотеки не редактировались. `custom.css` задаёт палитру через CSS-переменные, оформление hero и фотографий, состояния фокуса и отдельные уточнения для узкого экрана. Bootstrap-сетка и поведение компонентов остаются библиотечными.

## Сетка и компоненты

Главная использует `col-12 col-md-6 col-lg-4`: одна карточка на телефоне, две от 768 px, три от 992 px. В каталоге от 992 px фильтры занимают `col-lg-3`, товары — `col-lg-9`. Внутри каталога три карточки в строке появляются от 1200 px через `col-xl-4`, чтобы рядом с фильтром им хватало места.

## Доработки

- Локальные Bootstrap, фотографии и скрипты: сайт не обращается к CDN при просмотре.
- Дополнительные страницы избранного, доставки, контактов и сведений о данных формы.
- Поиск, фильтры и сортировка работают вместе. При смене фильтра каталог возвращается на первую страницу; сброс восстанавливает исходную подборку.
- Общие данные семи моделей в `js/products.js`. Страница товара и заявка выбирают модель по URL, характеристики выводятся из того же объекта.
- Избранное сохраняется между посещениями и синхронизируется между вкладками через событие `storage`. При запрете хранилища остаётся режим в памяти страницы.
- В заявке проверяются имя, email, российский телефон, количество от 1 до 10 и согласие. При выборе курьера появляется обязательный адрес. Доставка — 390 ₽, от 10 000 ₽ — бесплатно; самовывоз — бесплатно.
- Перед завершением показывается окно со всеми данными и суммой. Можно вернуться к форме и исправить поля.
- У мобильного меню есть закрытие по Escape и нажатию снаружи. У ошибок форм есть связь с полями через ARIA, видимый фокус и переход к первому неверному полю.
- Подвал находится внизу короткой страницы благодаря вертикальному Flexbox и растягивающемуся `main`.
- Реальные фотографии, единая зелёная палитра и читаемые исходники с отступами. Стандартные классы Bootstrap используются по назначению.

## Локальный запуск

Откройте `index.html` в браузере. Для предсказуемого общего localStorage между страницами удобнее локальный HTTP-сервер:

```sh
git clone https://github.com/TitaNik322/kr2-bootstrap-shop.git
cd kr2-bootstrap-shop
python -m http.server 8772 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8772`. Python нужен только для этого необязательного сервера. Устанавливать npm-пакеты не требуется.

## Проверка

Для самопроверки откройте страницы на ширинах 360, 768, 1024 и 1440 px. Проверьте меню, перестройку карточек, таблицу, поля и расположение подвала. В каталоге найдите `Keychron`, выберите тип и цену, смените сортировку и страницу, затем сбросьте фильтры. Сохраните товар в избранное и откройте соответствующую страницу. В форме проверьте пустые поля, телефон, изменение доставки и возврат из окна подтверждения.

Проверки выполняются локально; тестовые пакеты, генератор страниц и служебные отчёты для запуска сайта не нужны и в текущей структуре не хранятся. После обновления выполнены проверка синтаксиса JavaScript, проверка ссылок, ресурсов, подписей полей и ARIA-связей на восьми страницах. Отдельно в локальном DOM-окружении проверены фильтры, пагинация, избранное, данные всех семи моделей и сценарий заявки с расчётом доставки. Такое окружение не проверяет внешний вид и размеры: встроенный браузер во время проверки был недоступен.

## Публикация и ограничения

GitHub Pages публикует ветку `main`, папку `/(root)`. Адрес опубликованной версии указан в начале README. В СДО передаётся ссылка на репозиторий.

Основные компоненты объединены через [PR №1](https://github.com/TitaNik322/kr2-bootstrap-shop/pull/1). Финальные исправления оформлены в ветке `fix/kr2-final-check` через [PR №2](https://github.com/TitaNik322/kr2-bootstrap-shop/pull/2) в `main`, как предусмотрено практическим занятием №11.

Это статический frontend без backend, базы данных и оплаты. Форма проверяет данные в открытой вкладке, но не отправляет заявку в магазин. В localStorage записываются только идентификаторы избранного. Контактные значения на странице помощи статические.
