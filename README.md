## Запуск

Откройте `index.html` двойным щелчком. Сайт не использует fetch, сборщик, серверное API, внешние шрифты и CDN. Bootstrap и изображения работают без интернета. Для общего избранного между страницами рекомендуется HTTP-сервер: поведение localStorage у `file://` зависит от браузера.

```sh
git clone https://github.com/TitaNik322/kr2-bootstrap-shop.git
cd kr2-bootstrap-shop
python -m http.server 4173 --bind 127.0.0.1
```

Откройте [localhost:4173](http://localhost:4173). Python нужен только для необязательного локального сервера, генерации и статической проверки. Для просмотра сайта устанавливать зависимости не требуется.

## Локальное подключение Bootstrap

Используется compiled-версия **Bootstrap 5.3.8**. Файлы скачаны из официального npm-дистрибутива Bootstrap через jsDelivr и сохранены в репозитории. Во время работы сайта CDN не используется.

```html
<!-- В head каждой страницы, именно в таком порядке -->
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="css/custom.css">

<!-- В конце body; Bundle включает Popper -->
<script src="vendor/bootstrap/js/bootstrap.bundle.min.js"></script>
<script src="js/products.js"></script>
<script src="js/main.js"></script>
```

Лицензия Bootstrap MIT сохранена в `vendor/bootstrap/LICENSE`. Версия указана в заголовках оригинальных файлов. Исходные файлы фреймворка не изменены. Источник: [Bootstrap Download](https://getbootstrap.com/docs/5.3/getting-started/download/).

## Сетка и компоненты

Сетка строится на `container`, `row`, `col-12`, `col-md-*`, `col-lg-*`. Отступы задаются `g-4`, `gx-4`, `gy-5` и utility-классами Bootstrap. На главной товары расположены в одну колонку на телефоне, две от 768 px и три от 992 px. В каталоге от 992 px фильтры занимают `col-lg-3`, товары — `col-lg-9`.

| Компонент | Где используется |
| --- | --- |
| `navbar`, `collapse` | Общая навигация, мобильное раскрывающееся меню |
| `card`, `btn`, `badge` | Карточки товаров, кнопки, товарные метки |
| `alert` | Ошибки, информация об учебной форме, подтверждение, пустые результаты |
| `modal` | Пояснение заявки в товаре; проверка данных на странице заявки |
| `form-control`, `form-select` | Поля и выбор товара/категории |
| `input-group`, `form-check` | Телефон и поиск; согласие, фильтр скидок, способы получения |
| `accordion` | FAQ на страницах контактов и доставки |
| `nav-tabs`, `tab-pane` | Характеристики и условия доставки на странице товара |
| `toast` | Уведомления об изменении избранного |
| `pagination` | Реальное переключение страниц каталога по 6 товаров |
| `breadcrumb`, `table-responsive` | Навигация и адаптивная таблица характеристик |

## Самостоятельные доработки

1. **Полностью локальный Bootstrap.** Сайт продолжает работать при заблокированных внешних запросах. Все SVG-иллюстрации созданы для проекта и входят в репозиторий.
2. **Расширение страниц.** Избранное, доставка, контакты и пояснение о данных формы дополняют четыре обязательные страницы.
3. **Рабочий каталог.** Одновременные фильтры по названию, категории, предельной цене и скидке; три способа сортировки, сброс, счётчик результатов и пагинация. Параметр категории в ссылке с главной подставляет фильтр.
4. **Единые данные товаров.** Каждая карточка открывает своё название, описание, цену, иллюстрацию и характеристики. Из товара в заявку передаётся его идентификатор.
5. **Избранное.** Сохраняется между посещениями; обновляется в других вкладках через событие `storage`. При запрете хранилища доступен режим в памяти и уведомление.
6. **Сценарий заявки.** Количество от 1 до 10, проверка имени, почты, российского телефона, согласия и адреса курьера. Сумма пересчитывается сразу. Самовывоз бесплатен; курьер — 390 ₽, при сумме товаров от 10 000 ₽ — бесплатно. Перед подтверждением можно проверить данные и вернуться к редактированию.
7. **Дополнительные компоненты.** Accordion, tabs, toast и работающая pagination сверх обязательных компонентов.
8. **Собственное оформление.** Тёплая палитра, единые иллюстрации, аккуратная типографика, состояния карточек и ограниченный `custom.css`. Стандартные сетка и компоненты остаются Bootstrap.
9. **Адаптивность и доступность.** Проверки на 320, 375, 768, 1024 и 1440 px, клавиатурная навигация, видимый фокус, skip-link, label/name/required, ARIA для ошибок и статусов, `prefers-reduced-motion`.
10. **Проверяемость.** Статическая проверка ссылок/структуры, браузерные сценарии, отчёт доступности, матрица критериев и руководство для защиты.

## Организация кода

`tools/build.py` содержит исходные данные девяти товаров и общие функции `nav`, `card`, `shell`, `faq`. Он создаёт обычные читаемые HTML-файлы и `js/products.js`, чтобы шапка, карточки и данные на страницах не расходились. Пересборка: `python tools/build.py`. Запускать её для просмотра не нужно. Изменения общих шаблонов следует делать в генераторе, иначе они будут перезаписаны при следующей сборке. JavaScript хранится отдельно в `js/main.js`; CSS — в `css/custom.css`.

В собственных стилях применяются смысловые классы и БЭМ, например `product-card__visual`, `hero__title`, `site-footer__muted`. Классы Bootstrap не переименовываются по БЭМ. Идентификаторы используются для связей label/ARIA, якорей и JS, а не для CSS-оформления.

## Границы демонстрации

Это frontend-проект без backend и оплаты. Подтверждение означает, что учебная заявка прошла проверку в браузере; реальный заказ не создаётся. Контактные данные не записываются в localStorage и не отправляются по сети. Используйте вымышленные данные. Без JavaScript доступна статическая разметка, а фильтры, избранное, переключение товара по параметру и подтверждение формы требуют включённого JavaScript.

В СДО сдаётся **ссылка на репозиторий**, опубликованный сайт служит дополнительной демонстрацией. Для максимальной оценки нужно также уметь объяснить реализацию — для этого подготовлено руководство по защите.
